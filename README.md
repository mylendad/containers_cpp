# containers_cpp

Учебный проект: реализация контейнеров стандартной библиотеки C++ с нуля. Проект написан с учебной целью для изучения объектно-ориентированного программирования, шаблонов (templates), структур данных и алгоритмов.

## О проекте

`containers_cpp` — это собственная реализация STL-подобных контейнеров в пространстве имён `s21`. Вместо того чтобы пользоваться готовыми классами из `std::`, контейнеры написаны вручную: от структуры узлов и балансировки до итераторов.

## Статус проекта

Проект находится в процессе разработки.

Реализованы (tree-подобные контейнеры):

- `set` — упорядоченное множество уникальных элементов;
- `map` — упорядоченный ассоциативный массив «ключ → значение»;
- `multiset` — упорядоченное множество с допустимыми дубликатами.

Не завершено:

- `list` — только набросок интерфейса и черновой конструктор (не является рабочей реализацией);
- `const_iterator` — вынесен в отдельный файл, но ещё не подключён к контейнерам.

## Архитектура

```
src/
├── tree.h          # красно-чёрное дерево (общий базовый класс)
├── tree.tpp        # реализация узлов, вставки, удаления, балансировки
├── iterator.tpp    # обычный итератор
├── const_iterator.tpp  # константный итератор (в разработке)
├── set.h / set.tpp            # множество
├── map.h / map.tpp            # ассоциативный массив
├── multiset.h / multiset.tpp  # множество с дубликатами
├── list.cc          # черновик списка (не завершён)
└── test_*.cc        # тестовые программы (test_git, test_multiset, tests_tiltiset)
```

Базой всех реализованных контейнеров служит обобщённый класс `tree<T, AllowDuplicate>` — красно-чёрное дерево, параметризованное допустимостью дубликатов. На его основе:

- `set<Key>` запрещает дубликаты;
- `multiset<Key>` их разрешает;
- `map<Key, T>` хранит пары `std::pair<const Key, T>` и использует `Key` как ключ упорядочивания.

## Что реализовано в `tree`

- **Конструкторы и присваивание:** по умолчанию, из `std::initializer_list`, копирующий, перемещающий, операторы присваивания.
- **Итераторы:** `begin()`, `end()` + итератор с операциями `++`, `--`, `+=`, `-=`, разыменованием и `operator->`.
- **Полезное:** `empty()`, `size()`, `max_size()`, `clear()`.
- **Изменение:** `insert()`, `insert_many(...)` (вариадик), `erase()`, `swap()`, `merge()`.
- **Базовые операции красно-чёрного дерева:** `left_rotate`, `right_rotate`, `insert_fixup`, `delete_fixup`, `transplant`, поиск минимума/максимума, предшественника/преемника (`TreeSuccessor`, `TreeDescendant`), проверка инвариантов красно-чёрного дерева.
- `map` дополнительно предоставляет `at()`, `operator[]`, `insert(key, value)`, `insert_or_assign()`, `contains()`.
- `multiset` дополнительно предоставляет `count()`, `lower_bound()`, `upper_bound()`, `equal_range()`.

## Сборка и тесты

Проект использует только стандартную библиотеку C++ и не требует внешних зависимостей. Тестовые программы собираются напрямую компилятором:

```bash
c++ -std=c++17 src/test_git.cc      -o test_git
c++ -std=c++17 src/test_multiset.cc -o test_multiset
c++ -std=c++17 src/tests_tiltiset.cc -o tests_tiltiset
```

Заголовочная реализация (header-only) — контейнеры подключаются как `#include "set.h"` и не требуют отдельной компиляции в библиотеку.

## Быстрый пример

```cpp
#include "map.h"
#include "set.h"
#include <iostream>

int main() {
  s21::set<int> s = {5, 3, 8, 3};      // дубликат 3 игнорируется
  for (auto it = s.begin(); it != s.end(); ++it)
    std::cout << *it << ' ';           // 3 5 8
  std::cout << '\n';

  s21::map<std::string, int> m;
  m["one"] = 1;
  m["two"] = 2;
  std::cout << m.at("two") << '\n';    // 2
}
```

## Заметки

- Все контейнеры лежат в пространстве имён `s21`, чтобы не конфликтовать со стандартными классами.
- Дерево использует NIL-узлы (`tree_nil_`) и отдельный служебный узел `end_node_` для корректной работы итератора `end()`.
- Цвета узлов заданы макросами: `RED = false`, `BLACK = true`.
